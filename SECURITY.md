# Security Policy

## Supported versions

Only the latest code on the `main` branch is supported. No versioned releases are currently published.

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues or discussions. Use GitHub's **Report a vulnerability** form in the repository's **Security** tab to send a private report.

Include the affected commit or version, macOS version, steps to reproduce, and the potential impact. Do not attach clipboard archives or other personal data; a minimized proof of concept is preferred.

Please allow the maintainer a reasonable opportunity to investigate and prepare a fix before sharing vulnerability details publicly. There is currently no published response-time commitment.
